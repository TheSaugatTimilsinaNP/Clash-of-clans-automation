# Clash-of-clans-automation

Clash of Clans automation with python.
My own sloppy python code, modify and revise on your own to make it more effective.
All troops are deployed in Static way. No Dynamic troops deployment till date.

Made with Python (pyautogui). These two scripts will automate resource collection by attacking enemy base in Clash of Clans Mobile Game.
What you need to do: Install LD Player / Google Play Games and install Clash of Clans on your PC.
